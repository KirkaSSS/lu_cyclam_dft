# Coordination of Lu(III) in the Lu–cyclam complex: GFN2-xTB / DFT data and code

**Author:** Snežana Đurković · ORCID [0009-0007-6638-0682](https://orcid.org/0009-0007-6638-0682) · Vinča Institute of Nuclear Sciences, University of Belgrade

This package contains the code, structures and results of the independent DFT check in the
Supporting Information (Section S1) of the paper on the Lu(III) complex with cyclam
(1,4,8,11-tetraazacyclotetradecane). It tests whether the [Lu(cyclam)(H2O)5]3+ cation is
nona-coordinate (4N + 5O) or octa-coordinate (4N + 4O) with the fifth water molecule in the
second coordination sphere. The check complements the ωB97X-D4/def2-TZVP optimizations in the
main text.

Main result: the octa-coordinate [Lu(cyclam)(H2O)4]3+·H2O is the lowest-energy structure; the
most stable nona-coordinate isomer lies 6.9 kcal/mol higher (PBE0-D3(BJ)/def2-SVP, ddCOSMO water,
on GFN2-xTB geometries).

**Nona-coordinate isomer:** a structure of the same composition, [Lu(cyclam)(H2O)5]3+, in which Lu(III)
is bonded to nine donor atoms: the four cyclam N atoms and the O atoms of all five water molecules
(coordination number 9; 4N + 5O). It is an isomer of the octa-coordinate form because both contain
the same atoms; they differ only in where one water molecule sits: bound to Lu, or hydrogen-bonded in
the second coordination sphere (4N + 4O + H2O). In the code, a donor atom counts as bound when its
distance from Lu is below 3.0 Å.

## Model and input

No experimental data enter the calculation. The input is the chemical model of the cation:
one Lu3+, one cyclam (SMILES in `scripts/lib.py`) and five water molecules, total charge +3.
Counter-ions (BF4−, Na+) are not included; water is treated as a continuum (ε = 78.36).
All starting geometries are generated by the code; random numbers use fixed seeds.

## Protocol

| Step | Script | What it does |
| --- | --- | --- |
| 1 | `01_conformers.py` | 16 cyclam conformers (RDKit, MMFF94) × 3 water distributions (5+0, 4+1, 3+2 inner + outer) = 48 structures; GFN2-xTB optimization in ALPB water (f_max < 0.03 eV/Å) |
| 2 | `02_rank_xtb.py` | Ranks all structures by GFN2-xTB energy (`xtb_ranking.json`) |
| 3 | `03_cn9_cages.py` | Restrained 4N + 5O cages from the best structures, then unrestrained relaxation |
| 4 | `04_calibration_aqua.py` | Reference system: [Lu(H2O)9]3+ vs [Lu(H2O)8]3+·H2O |
| 5 | `05_dft_single_point.py` | PBE0/def2-SVP, ECP28MWB on Lu, density fitting, ddCOSMO water, + D3(BJ); Mulliken charge on Lu and dipole moments |
| 6 | `06_summary.py` | Table of relative energies |
| 7 | `07_compare.py` | Compares a new `dft.jsonl` with the deposited one |
| 8 | `08_figures.py` | Python version of Figs. S1–S2 (the published figures come from `matlab/lu_dft_figures.m`) |

`run_all.py` runs steps 1–6 in order.

## Requirements

- Linux or macOS (on Windows: WSL2). PySCF does not run natively on Windows.
- Python 3.10–3.13 (results were produced with Python 3.13 on Linux x86_64), ≥ 8 GB RAM.

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Reproducing the results

All commands from the `scripts/` folder.

**A. Inspect the deposited results (seconds)**

```bash
python 06_summary.py ../results/dft/dft.jsonl
python 08_figures.py
```

**B. Recompute the DFT energies from the deposited geometries (~1 h 50 min on 2 cores)**

```bash
python run_all.py --skip-xtb --threads 4
python 07_compare.py ../work/dft.jsonl
```

**C. Full pipeline including the conformer search (~2 h on 2 cores)**

```bash
python run_all.py --threads 4 --jobs 4
python 07_compare.py ../work/dft.jsonl
```

`07_compare.py` reports the difference from the deposited energies in kcal/mol and exits with
code 1 if any exceeds the tolerance (default 0.05 kcal/mol).

| --- | --- | --- | --- |
| `s3_2_10` | 4N + 4O + H2O (second sphere) | 0.0 | 0.0 |

| `cn9_s3_2_10` | 4N + 5O | 14.9 | 15.9 |

File names: `sN_M_K` = start with N inner and M outer water molecules, conformer seed K
(the final coordination can differ from the start); `cn9_*` = 4N + 5O cage; `aq*` = Lu3+ aqua ion.

## Notes on reproducibility

- The deposited `cn9_*.xyz` files are the restrained geometries used for DFT. A new run of step 3
  writes them as `cn9_*_restrained.xyz` (identical meaning) and also the released geometries
  `cn9_*.xyz`; release changes the GFN2-xTB energy by < 0.1 kcal/mol and keeps CN 9.
- Starting structures use fixed seeds, so with the versions in `requirements.txt` the conformer
  search gives the same structures. Other versions or platforms can change the numerics slightly,
  which may change which conformer ranks lowest; check `work/xtb_ranking.json` before step 5.
  Route B does not depend on this and reproduces the DFT energies directly.
- Energies are electronic energies from single points on GFN2-xTB geometries with a double-zeta
  basis, without thermal or entropic corrections. GFN2-xTB is used for geometries only: in the
  aqua-ion test it wrongly favours CN 9 (by 8.8 kcal/mol), whereas the DFT level reproduces the
  experimental CN 8.
- Dipole moments of a cation depend on the origin; both the centre of nuclear charge and the Lu
  position are reported.

## MATLAB

`matlab/` needs no toolboxes (MATLAB R2020a or newer for figure export).

```matlab
cd lu_cyclam_dft/matlab
T = lu_dft_results;      % table of the deposited results
lu_dft_figures           % Figs. S1 and S2 (PNG 300 dpi and PDF) in ../figures
lu_dft_setup             % once: Python environment (Windows: in WSL2)
T = lu_dft_run('SkipXtb', true, 'Threads', 4);   % route B from MATLAB
```

On Windows, `lu_dft_setup` and `lu_dft_run` need WSL2 with Ubuntu. One-time setup: in PowerShell
as administrator `wsl --install -d Ubuntu`, restart, then in Ubuntu
`sudo apt update && sudo apt install -y python3-venv python3-pip`. `lu_dft_results` and
`lu_dft_figures` work without Python or WSL.
